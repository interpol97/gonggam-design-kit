# 레이아웃 패턴 10종 — 어떤 장에 무엇을 쓰나

> 뼈대는 `templates/deck.html`. **처음부터 CSS를 짜지 않는다.** 그 파일을 복사해 내용만 바꾼다.
> 토큰(`:root`)만 갈아끼우면 덱 전체의 색·크기가 바뀐다.

---

## 고르는 법

| 하려는 말 | 패턴 | 클래스 |
|---|---|---|
| 시작한다 | 표지 | `.cover` |
| **한 가지를 못 박는다** | 한 문장 | `.statement` |
| 숫자 하나가 논거다 | 큰 숫자 | `.metric` |
| 둘을 견준다 | 2단 비교 | `.split` |
| 할 일을 나열한다 | 항목 | `.list-slide` |
| 관계·흐름을 보인다 | 도해 | `.diagram` |
| 여러 값을 비교한다 | 표 | `.table-slide` |
| 남의 말을 빌린다 | 인용 | `.quote` |
| 장을 넘긴다 | 섹션 전환 | `.section-break` |
| 행동을 요청한다 | 마무리 | `.closing` |

**같은 패턴을 3연속 쓰지 않는다.** 항목 슬라이드가 네 장 이어지면 청중이 잠든다.
설득 덱이면 `.statement`·`.metric`을, 강의 덱이면 `.diagram`·`.split`을 축으로 삼는다.

---

## 패턴별 규칙

**`.cover`** — 제목 2줄 이내. 부제 한 줄. 하단 메타는 소속·날짜·자리 셋까지.

**`.statement`** — **한 장에 문장 하나.** 20자 안팎에서 끊는다. 강조는 `<span class="accent">` 한 곳에만.

**`.metric`** — 숫자는 `.num`, 단위는 그 안의 `<small>`. **숫자 하나만** 크게. 두 개를 나란히 크게 두면 둘 다 안 읽힌다. 밑에 `.what`(무슨 숫자인가)과 `.note`(어떻게 나온 숫자인가)를 붙인다. **근거 없는 숫자는 올리지 않는다.**

**`.split`** — 왼쪽에 통념·기존, 오른쪽에 우리. 오른쪽 열에 `.on`을 붙이면 강조색이 든다. 항목은 양쪽 **같은 수**로.

**`.list-slide`** — 항목 **3~5개**. 번호(`.n`)는 순서가 실제 의미 있을 때만. 각 항목은 `<b>핵심어</b> — 설명` 꼴로.

**`.diagram`** — 인라인 SVG. `viewBox="0 0 900 220"` 기준으로 그리면 자동으로 맞는다.
- 상자 `class="dg-box"`, 강조 상자 `dg-box-on`
- 화살표 `<path class="dg-arrow" d="M… H…"/>` (마커는 이미 정의돼 있다)
- 글자 `dg-t`(제목) / `dg-s`(부연)
- **상자 5개를 넘기지 않는다.** 넘으면 두 장으로 나눈다

**`.table-slide`** — 행 6·열 4가 한계. 숫자 칸에 `class="num"`(우측 정렬·등폭). 강조할 행에 `class="hi"`.

**`.quote`** — 24자 안팎. `.who`에 **누가·언제·동의 여부**를 적는다. 창작 인용은 쓰지 않는다.

**`.section-break`** — 잉크 배경. **10장 넘는 덱에서만.** 짧은 덱엔 흐름을 끊는다.

**`.closing`** — **행동 하나.** `.cta`에 동사를 넣는다("상담 신청하기"). 이 장이 가장 오래 떠 있으니 연락 수단을 여기 둔다.

---

## 만들 때

1. `templates/deck.html`을 복사한다
2. `:root` 토큰에서 `--accent`와 `--bg`만 상황에 맞게 바꾼다 (나머지는 손대지 않는다)
3. `<section class="slide …">` 블록을 필요한 만큼 복사·삭제한다
4. `.pageno`와 `.prog`의 `width:%`를 장수에 맞게 고친다
5. 브라우저로 열어 확인한다 — **← →** 이동, **F** 전체화면, **P** PDF, **D** 어두운 테마

## 손대지 말 것

- **타이포 스케일**(`--t-*`) — 본문 21pt 하한이 여기서 지켜진다. 줄이면 뒷자리에서 안 읽힌다
- **`--pad`** — 안전 여백. 프로젝터 가장자리가 잘린다
- 그림자·모서리 값을 장마다 다르게 주는 것

## 어두운 테마

`<body class="dark">`. 웨비나 화면 공유에는 쓸 만하지만 **불 켠 강의실에서는 뿌옇게 뜬다.**
템플릿은 어두운 테마에서 줄간·자간·굵기 **세 축을 자동으로 보정**한다 — 직접 더 손대지 않는다.
