# 업무 플로우 — 무엇을 묻고, 어떤 순서로 만드나

> 덱 제작 요청이 들어오면 **이 순서대로** 진행한다.
> 사용자가 이미 준 정보는 다시 묻지 않는다. 빈 칸만 묻는다.

---

## 0단계 — 소재부터 확인한다 (묻기 전에)

**먼저 볼 것이 있는지 확인한다.** 있으면 대부분의 질문이 저절로 채워진다.

- 첨부한 파일 (한글·워드·PDF·엑셀·기존 PPT·사진)
- 붙여넣은 글
- 지난 대화에서 만든 자료

있으면 **읽고 나서** 아래를 묻되, 읽어서 아는 것은 **확인만** 받는다.
없으면 "무엇을 가지고 만들까요 — 자료가 있으면 올려 주시고, 없으면 대화로 만들겠습니다"로 시작한다.

---

## 1단계 — 한 번에 묶어 묻는다

**질문을 하나씩 던지지 않는다.** 아래를 한 화면에 묶어 묻고, 답을 받아 한 번에 진행한다.
사용자가 모르겠다고 하면 **기본값으로 진행하고 나중에 바꿀 수 있다고 알린다.**

### 필수 5

| # | 묻는 것 | 선택지·기본값 |
|---|---|---|
| 1 | **주제** — 무엇에 대한 발표입니까 | (자유 입력) |
| 2 | **모드** — 청중이 무엇을 하면 성공입니까 | **설득**(결정·신청) / **강의**(이해·기억) / **보고**(근거 확인) |
| 3 | **청중** — 누가, 몇 명, 어디서 봅니까 | 예: 학부모 40명 · 저녁 강의실(불 켬) · 빔프로젝터 |
| 4 | **임무** — 발표가 끝나고 **딱 하나** 하게 만들 행동은 | 예: 개별 상담 신청 |
| 5 | **분량** — 발표 몇 분입니까 | 기본 20분 → **12~15장** (계획의 70%) |

### 필수 6번 — 무엇으로 받을지

| # | 묻는 것 | 선택지 |
|---|---|---|
| 6 | **어떤 파일로 드릴까요** | **HTML**(브라우저 발표·PDF) / **PPTX**(직접 수정) / 둘 다 |

**기본은 HTML 이다.** 안 깨지고 빠르다.
`.pptx` 는 **받는 사람이 직접 고쳐야 할 때**만 고른다 — 그때는 `pptx-spec.md` 규격으로 만들고,
폰트를 맑은 고딕으로 바꾸고 자동 맞춤을 끈다.

### 선택 5 — 안 물어도 되지만 있으면 좋다

| # | 묻는 것 | 기본값 |
|---|---|---|
| 7 | **제목** — 표지에 넣을 말 | 없으면 **3안을 만들어 고르게 한다** |
| 8 | **색·분위기** | 아래 «색·분위기» 절에서 말로 고르게. 기본 `t-trust` |
| 9 | **브랜드 색·로고** | 있으면 테마보다 우선. hex 또는 로고 파일 |
| 10 | **사진·도표** — 넣을 이미지가 있으면 | 없으면 넣지 않는다 (빈 자리를 만들지 않는다) |
| 11 | **금지 사항** — 쓰면 안 되는 표현·숫자 | 없으면 표준 검수만 |

### 7번 색·분위기 — 말로 고르게 한다

**테마 코드명을 보여주지 않는다.** "t-cobalt 로 할까요"는 아무도 못 고른다.
**분위기를 말로 묻고** 코드는 우리가 고른다.

> **"어떤 느낌이면 좋겠습니까?"**

| 고르는 말 | 테마 | 색 | 어울리는 자리 |
|---|---|---|---|
| **신뢰감 있게, 무난하게** | `t-trust` | 코발트블루 | **설명회 기본값** · 입시·성적 |
| 단정하고 맑게 | `t-clear` | 밝은 파랑 | 브랜드 소개, 제품 |
| 한국적으로 친근하게 | `t-friendly` | 토스풍 파랑 | 학부모 안내, 앱 소개 |
| 학술적으로, 격식 있게 | `t-academy` | 짙은 파랑 | 정규 과정, 기관 제출 |
| 선명하고 또렷하게 | `t-cobalt` | 코발트 | 데이터·기술 |
| **친근하고 화사하게** | `t-fresh` | 초록+노랑 | **초·중등** 학부모/학생 |
| 성장하는 느낌으로 | `t-sprout` | 연두 | 방학 특강, 성장 서사 |
| 학습·성취 느낌으로 | `t-mint` | 민트+블루 | 중·고등 |
| 차분하고 정통적으로 | `t-forest` | 진초록 | 오래된 학원, 전통 |
| 세련되게 | `t-violet` | 보라 | 프리미엄 특강, 신규 브랜드 |
| **따뜻하고 부드럽게** | `t-sunrise` | 크림+주황 | **초등**, 감성 |
| 활기차게, 눈에 띄게 | `t-mango` | 주황 | 모집, 이벤트 |
| **강하게 주목시키기** | `t-focus` | 레드 | **마감 고지**, 긴급 |
| 따뜻하면서 주목되게 | `t-coral` | 코랄 | 후기, 사례 |

**고르지 못하면 `t-trust` 로 간다.** 신뢰형이 어디에나 무난하다.

### 색을 더 정확히 정할 때 (선택)

원장이 브랜드 색을 갖고 있으면 테마보다 그쪽이 우선이다.

> **"학원 대표색이 있습니까? 있으면 색상 코드(#RRGGBB)나 로고를 주십시오."**

- **hex 를 주면** 그 색을 `--accent` 로 쓰고, 나머지(배경·글자·괘선)는 가장 가까운 테마에서 가져온다
- **로고만 주면** 로고에서 주된 색을 뽑아 같은 방식으로 쓴다
- **너무 밝은 색**(노랑·연두 계열)은 흰 배경에서 글자로 못 쓴다 → 그 색은 `--pop`(숫자·형광펜)으로 돌리고 `--accent` 는 한 단계 어둡게 만든 값을 쓴다
- 색이 둘 이상이면 **하나만 강조로.** 나머지는 쓰지 않거나 `--pop` 하나까지만

### 밝게 갈까 어둡게 갈까

**묻지 말고 사용 장면에서 정한다.** 다만 애매하면 한 번 확인한다.

| 어디서 보는가 | 결정 |
|---|---|
| 강의실·회의실 (**불을 켠다**) | **밝은 배경** — 기본값. 어두운 배경은 뿌옇게 뜬다 |
| 화면 공유 (웨비나·줌) | 밝은 배경이 무난. 어둡게 하고 싶으면 `dark` |
| 조명을 끄고 큰 스크린 | 어두운 배경도 가능 |

## 2단계 — Design Read 를 한 줄로 되짚는다

받은 답을 **한 문장으로 확인받는다.** 여기서 어긋나면 다 만들고 뒤집는 것보다 싸다.

> "설득 덱으로 읽었습니다. 예비고1 학부모 40명, 저녁 강의실(불 켬), 임무는 개별 상담 신청 하나, 25분 · 14장, 테마는 신뢰형(코발트블루). 이대로 갈까요?"

## 3단계 — 목차를 먼저 낸다 (장표를 만들기 전에)

**바로 만들지 않는다.** 장별 제목과 레이아웃만 표로 낸다.

| 장 | 제목 | 레이아웃 |
|---|---|---|
| 1 | (표지 제목) | `.cover` |
| 2 | 중3까지 80점대였던 학생이 52점을 받습니다 | `.statement` |
| 3 | 하위권 오답 68%가 어법 | `.metric` |
| … | | |
| 14 | 개별 상담 신청하기 | `.closing` |

여기서 확인할 것:
- 같은 레이아웃이 **3연속**인 곳은 없는가
- 마지막 장이 **행동 하나**인가
- 장수가 분량에 맞는가 (1장 ≈ 1.5~2분)

승인받고 나서 만든다.

## 4단계 — 만든다

`templates/deck.html` 을 복사해 채운다. **처음부터 CSS를 짜지 않는다.**
패턴별 규칙은 `layouts.md`. 문구는 `korean-writing`.

## 5단계 — 검수하고 넘긴다

`SKILL.md` 의 검증 목록을 돌린다. 특히 **실제로 띄워 보고 뒤에서 읽어봤는가.**

그다음 사용자에게 셋 중 무엇이 필요한지 묻는다.

| 필요한 것 | 어떻게 |
|---|---|
| **그대로 발표** | 브라우저로 열고 `F` 전체화면. `←→` 이동 |
| **PDF로 배포** | `P` 눌러 인쇄 → PDF로 저장 |
| **PPTX로 직접 수정** | `pptx-spec.md` 규격으로 `.pptx` 를 만든다. **HTML 을 변환하는 게 아니라 규격에 맞춰 새로 짠다** |

PPTX 로 갈 때는 **폰트를 맑은 고딕으로 바꾸고 자동 맞춤을 끈다** — 안 그러면 받는 PC 에서 깨지고 글자가 줄어든다.

**배포용 인쇄본**이 따로 필요한지도 묻는다 — 슬라이드를 그대로 인쇄하면 여백투성이라, A4 1~2장으로 다시 짜는 편이 낫다.

---

## 다시 묻지 않는 것

한 번 받은 답은 **그 대화 안에서 다시 묻지 않는다.** 특히 청중·조명·임무는 덱 전체를 지배하므로 처음에 받아 끝까지 유지한다.
사용자가 중간에 "테마 바꿔줘"라고 하면 **토큰만 갈아끼운다.** 내용을 다시 만들지 않는다.

## 사용자가 급할 때

"그냥 빨리 만들어줘"라고 하면 **1·3번만 묻고** 나머지는 기본값으로 간다.

> 주제 / 청중 → 나머지는 **설득 모드 · `t-trust` · HTML · 12장 · 20분**

만든 뒤에 "테마와 장수는 바꿀 수 있습니다"라고 알린다.
