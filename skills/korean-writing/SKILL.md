# 한글 글쓰기 (Korean Writing)

이 스킬은 **단독으로 쓰이지 않는다.** 다른 스킬이 만든 한글 산출물 위에 항상 겹쳐 적용한다.

디자인·마케팅 도구는 대부분 영어권에서 만들어졌다. 그 논리를 한국어로 옮기면 세 가지가 반드시 나온다.
**① 번역투 ② 미국식 직설 화법 ③ 학부모에게 안 통하는 논리 구조.**
이 스킬이 그 셋을 걷어낸다.

---

## 0. 가장 먼저 정하는 것 — 독자

한글 산출물은 독자에 따라 문체가 **완전히** 달라진다. 섞으면 전부 실패한다.

| 독자 | 종결 | 핵심 | 금지 |
|---|---|---|---|
| **결정자·보호자** | ~습니다 (드물게 ~해요) | 근거·숫자·다음 계획 | 불안 자극, 과장, 당사자 비하 |
| **당사자·학습자** | 짧고 직접적으로 | 할 일 1~2개 | 훈계, 비교, 장문 |
| **검색 유입(블로그)** | ~해요 / ~습니다 혼용 | 정보 먼저, 검색어 그대로 | 광고 냄새, 학원 자랑 선행 |
| **공개 게시(슬라이드·전단)** | 명사형·짧은 문장 | 2초 안에 읽히는 한 줄 | 정보 과다 |

**어느 독자인지 모르면 쓰기 전에 묻는다.**

## 1. 번역투 제거 ★가장 자주 걸리는 문제★

영어 스킬을 거친 글에는 아래 패턴이 반드시 섞인다. 전부 잡는다.

| 번역투 | 고침 |
|---|---|
| ~을 **가지고 있습니다** | ~이 있습니다 |
| ~에 대한 **접근법** | ~하는 방법 |
| ~을 **제공합니다** | ~합니다 / ~해 드립니다 |
| ~하는 것을 **도와줍니다** | ~하게 됩니다 / ~할 수 있습니다 |
| **귀하의** 자녀 | 아이 / 학생 |
| ~에 **초점을 맞춥니다** | ~에 집중합니다 |
| **최적화된** 학습 경험 | 아이에게 맞는 수업 |
| ~을 **극대화** / **최대화** | 최대한 ~합니다 |
| **효과적인** 솔루션 | (구체적으로 무엇인지 쓴다) |
| ~할 **필요가 있습니다** | ~해야 합니다 |
| **~에 있어서** | ~에서 / ~할 때 |
| ~되어**지다**, ~하게 **되어집니다** | ~됩니다 |
| **가장** ~한 것 중 **하나** | (통째로 삭제하고 단정하거나 근거를 댄다) |

**구조 번역투**
- **긴 관형절** — "지난 시험에서 하락한 성적을 보인 학생들을 위한 맞춤 보강 프로그램" → "지난 시험에서 성적이 떨어진 학생은 따로 보강합니다"
- **명사화** — "성적 향상의 실현" → "성적이 오릅니다"
- **피동 남용** — "분석이 진행되었습니다" → "분석했습니다"
- **주어 과잉** — 한국어는 주어를 자주 생략한다. "저희 학원은 ~합니다"를 매 문장 반복하지 않는다

상세 목록: `references/anti-translationese.md`

## 2. AI 티 제거

읽는 사람은 AI가 쓴 글을 귀신같이 알아본다. 아래가 신호다.

- **세 개씩 나열하는 습관** — "체계적이고, 전문적이며, 효율적인"
- **속 빈 형용사** — 체계적/전문적/효율적/최적의/차별화된/맞춤형. **전부 삭제하고 사실로 대체**
  - ✗ "체계적인 커리큘럼" → ✓ "3주마다 단원평가로 진도를 점검합니다"
- **모든 문장이 같은 길이** — 실제 사람은 짧은 문장과 긴 문장을 섞는다
- **결론 없는 균형** — "장단점이 있습니다"로 끝내지 않는다. 학부모는 판단을 원한다
- **과한 이모지·굵은 글씨** — 강조가 많으면 강조가 없다
- **"~에 대해 알아보겠습니다" 도입** — 바로 본론으로

**교정 원칙: 형용사를 지우고 그 자리에 숫자나 사실을 넣는다.**

## 3. 보호자·결정자 문체 규칙

### 논리 순서 (이 순서를 지킨다)
**사실 → 원인 → 조치 → 요청**

> ✗ "아이가 요즘 집중을 못 합니다. 관심 좀 가져주세요."
> ✓ "이번 시험에서 어법 문항 6개 중 4개를 틀렸습니다(사실). 3단원 진도 때 결석이 두 번 있었습니다(원인). 이번 주부터 그 부분만 따로 보강하고 있습니다(조치). 집에서 단어 확인만 5분 봐주시면 좋겠습니다(요청)."

### 반드시 지킬 것
- **먼저 연락한다.** 학부모가 먼저 묻게 하면 이미 늦다
- **변명하지 않는다.** "시험이 어려웠습니다"를 첫 문장에 쓰지 않는다
- **학생을 낮추지 않는다.** "노력을 안 합니다"는 학부모에게 학원 무능으로 읽힌다
- **다음 계획을 반드시 붙인다.** 계획 없는 통보는 불안만 남긴다
- **숫자는 근거와 함께.** 출처 없는 숫자는 쓰지 않는다

### 금지 화법 — 불안 자극
학원 마케팅에서 가장 흔하고, 가장 신뢰를 깎는 방식.

| 금지 | 대체 |
|---|---|
| "이대로면 큰일 납니다" | "지금 보완하면 다음 시험에 반영됩니다" |
| "지금 안 하면 늦습니다" | "이 시기에 하면 효율이 가장 높습니다" |
| "옆집 아이는 벌써~" | (다른 학생과 비교하지 않는다) |
| "고등 가서 후회합니다" | "고등 과정에서 이 부분이 다시 나옵니다" |

불안 화법은 단기 등록은 만들지만 재등록을 못 만든다. 그리고 표시광고법 리스크를 키운다.

## 4. 검색 유입 글(블로그) 문체

- **제목에 사람들이 실제로 치는 말**을 넣는다
  - ✗ "중간고사 이후 학습 전략 제언" → ✓ "○○중 2학년 영어 중간고사, 뭐가 어려웠나"
- **학교명·학년·과목·지역**을 문장 안에 자연스럽게 넣는다
- 첫 3줄에 결론을 준다. 학부모는 스크롤하지 않는다
- **정보 80 / 학원 20.** 학원 이야기는 뒤에
- 존댓말 ~해요체가 ~습니다체보다 블로그에서 잘 읽힌다. 단, 성적·법적 사안은 ~습니다체
- 문단은 2~3문장. 모바일에서 읽힌다는 전제

---

## 5. 짧은 글 (문자·알림톡·전단)

- **알림톡: 한 건에 용건 하나.** 두 개 이상이면 나눠 보낸다
- 첫 줄에 누구 이야기인지 밝힌다 — "○○ 어머님, ○○이 중간고사 결과 안내드립니다"
- 전단·현수막: **한 줄 + 한 정보.** 읽는 시간 2초
- 전화번호보다 카카오 채널·QR (전화는 심리적 장벽이 높다)
- 단체 발송에 **다른 학생 정보가 섞이지 않았는지** 반드시 확인 (개인정보)

---

## 6. 발행 전 체크리스트

- [ ] 독자가 하나로 정해져 있는가
- [ ] 번역투 표현이 남아 있지 않은가 (§1 표 대조)
- [ ] 속 빈 형용사를 사실·숫자로 바꿨는가 (§2)
- [ ] 불안 자극 화법이 없는가 (§3)
- [ ] 숫자에 근거·표본·기간이 붙어 있는가
- [ ] 과장 표현(100%·무조건·보장·1위)이 없는가
- [ ] 개인 특정 정보가 공개 글에 없는가
- [ ] 소리 내어 읽었을 때 걸리는 문장이 없는가 ★ 가장 확실한 검사
