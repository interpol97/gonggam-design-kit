## 속 빈 형용사 — 전부 삭제하고 사실로

| 삭제 | 대체 예 |
|---|---|
| 체계적인 | "3주마다 단원평가로 점검합니다" |
| 전문적인 | "영어만 12년 가르쳤습니다" |
| 효율적인 | "같은 시간에 문제를 두 배 풉니다" |
| 최적의 | "이 학년에는 이 순서가 맞습니다" |
| 차별화된 | "○○중 기출만 8회분을 씁니다" |
| 맞춤형 | "학생마다 오답 유형별로 다른 과제를 줍니다" |
| 혁신적인 | (거의 항상 삭제) |
| 검증된 | (근거를 못 대면 삭제 — 표시광고법) |

**규칙: 형용사를 지운 자리에 숫자나 구체적 사실을 넣는다. 못 넣으면 그 문장은 필요 없는 문장이다.**

## 구조

**긴 관형절을 문장으로 푼다**
- ✗ 지난 시험에서 목표 점수에 도달하지 못한 학생들을 위한 집중 보완 프로그램
- ✓ 지난 시험에서 목표 점수를 못 넘은 학생은 따로 보완합니다

**명사화를 동사로**
- ✗ 성적 향상의 실현 → ✓ 성적이 오릅니다
- ✗ 학습 습관의 형성 → ✓ 공부 습관이 잡힙니다
- ✗ 진도의 조정이 필요합니다 → ✓ 진도를 조정하겠습니다

**피동을 능동으로**
- ✗ 분석이 진행되었습니다 → ✓ 분석했습니다
- ✗ 보강이 실시될 예정입니다 → ✓ 보강하겠습니다
- ✗ ~라고 생각되어집니다 → ✓ ~라고 봅니다

**주어 반복 제거** — 한국어는 주어를 생략한다
- ✗ 저희 학원은 A합니다. 저희 학원은 B합니다. 저희 학원은 C합니다.
- ✓ A합니다. B도 함께 합니다. C까지 봅니다.

**복수 표지 남용**
- ✗ 학생들의 성적들이 → ✓ 학생 성적이

**접속 부사 과잉** — 또한/그러나/따라서를 문단마다 쓰지 않는다. 한국어는 접속 없이 이어져도 읽힌다.

## 세 개씩 나열하는 습관 (AI 신호)

- ✗ "체계적이고, 전문적이며, 효율적인 수업"
- ✓ "3주마다 점검하는 수업" (하나만, 대신 구체적으로)

세 개를 쓰려면 셋이 **서로 다른 것**이어야 한다. 같은 말의 반복이면 하나로 줄인다.

## 문장 길이

- 한 문장 **40자 안팎**을 기준으로. 60자를 넘으면 자른다
- 모든 문장이 같은 길이면 기계처럼 읽힌다. **짧은 문장을 의도적으로 섞는다**
- 알림톡·전단은 20자 안팎

## 최종 검사

**소리 내어 읽는다.** 숨이 차거나 혀가 걸리는 문장은 번역투다. 이 검사가 위의 모든 표보다 정확하다.
