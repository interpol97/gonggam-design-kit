## webinar.html — 무엇을 보여주나

킷 소개를 **킷 자체로** 만든 자료입니다. 규칙이 실제로 적용된 모습을 그대로 볼 수 있습니다.

- 스킬 세팅 (설치 3갈래·폴더 구조)
- 진행 흐름 (5단계·묻는 장면 목업·테마 비교 목업)
- **주제 5종** — 고교학점제 / 고교선택 / ○○고 수학 1등급 / 중2 첫 내신 / 방학 특강
  같은 킷으로 모드·색·장수·주력 레이아웃만 바뀌는 것을 보입니다

## motion-demo.html — 모션 5종

`../skills/gonggam-design-deck/references/motion-prompts.md` 의 다섯 가지가 실제로 동작합니다.

① 스태거 상승 ② 형광펜 긋기 ③ 숫자 카운트업 ④ 낱말 모핑 ⑤ 도해 선 그리기

**덱 하나에 하나만** 고릅니다. 설득 ①+② / 강의 ①+⑤ / 보고 ①만.
