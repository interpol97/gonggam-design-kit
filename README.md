# 공감 PPT 킷

PPT·발표자료를 **"AI가 만든 티" 없이** 만들기 위한 클로드 스킬 셋입니다.

클로드에게 "PPT 만들어줘"라고 하면 대개 비슷한 것이 나옵니다. 제목 위에 작은 대문자 라벨,
아이콘 카드 세 개, 그라데이션, 이모지. 이 킷은 그런 기본값을 막고,
**뒷자리에서 읽히는지 / 한 장에 메시지가 하나인지**를 기준으로 판정합니다.

## 스킬 셋

| 스킬 | 하는 일 |
|---|---|
| **gonggam-design** | 만들기 전 방향 잡기 — 색·폰트·시그니처, 품질 바닥선, 실눈 검사, 거부 목록, 기존 자료 개선 절차 |
| **gonggam-design-deck** | 슬라이드 규칙 — 모드 3종, 크기 하한, 투사 환경, 한 장 한 메시지, **PPTX 규격** |
| **korean-writing** | 한글 문체 — 번역투 40여 항목, 속 빈 형용사 → 사실 치환, 불안 자극 화법 차단 |

세 개가 이어서 동작합니다. `-deck` 이 시작할 때 `gonggam-design` 을 먼저 읽고,
한글 문구가 나올 때 `korean-writing` 을 겹쳐 적용합니다.

## 먼저 보시면 좋습니다

`examples/` 에 이 킷으로 만든 완성본이 들어 있습니다. 브라우저로 그냥 열면 됩니다.

| 파일 | 무엇 |
|---|---|
| `examples/webinar.html` | 킷 소개 웨비나 덱 20장 — **킷 자체로 만든 것** |
| `examples/motion-demo.html` | 글자 모션 5종이 돌아가는 데모 8장 |

`←` `→` 이동 · `F` 전체화면 · `P` PDF · **`T` 테마 14종** · `D` 어둡게

## 설치 — 방법 셋

### A. 압축 풀어 넣기 (가장 쉬움)

내려받은 `skills/` 안의 폴더 **세 개**를 아래 위치에 복사합니다.

```
Windows   C:\Users\<사용자명>\.claude\skills\
Mac       ~/.claude/skills/
```

이렇게 됩니다.

```
~/.claude/skills/
├─ gonggam-design/
├─ gonggam-design-deck/
└─ korean-writing/
```

**클로드 코드를 새로 열면** 적용됩니다. (실행 중인 창에는 반영되지 않습니다)

### B. Cowork 에 스킬로 추가

Cowork(설치형 데스크톱 앱)의 **스킬 추가**에서 `skills/` 안의 세 폴더를 넣습니다.
넣고 나면 "PPT 만들어줘" 만으로 이 규칙이 적용됩니다.

> **PPTX 파일은 Cowork 이 만듭니다.** 이 킷은 HTML 로 만들고, 그대로 발표하거나
> PDF 로 뽑을 수 있습니다. 원장님이 직접 수정해야 해서 `.pptx` 가 필요하면
> "이걸 pptx로 만들어줘" 라고 하시면 됩니다 — 별도 설치가 필요 없습니다.

### C. 클로드 코드에 플러그인으로 (업데이트 자동)

```
/plugin marketplace add interpol97/gonggam-ppt-kit
/plugin install gonggam-ppt-kit@gonggam-ppt-kit
```

## 쓰는 법

**스킬 이름을 부를 필요가 없습니다.** 요청 내용에 맞는 것을 클로드가 알아서 꺼냅니다.

```
설명회용 PPT 만들어줘
이 자료로 발표자료 만들어줘        ← 파일을 올리면 읽고 시작합니다
이 장표 좀 봐줘 — 뭐가 문제인지
발표자료가 촌스러운데 고쳐줘
```

### 물어보는 것

바로 만들지 않고 **한 번에 묶어 묻습니다.**

| 필수 | 선택 |
|---|---|
| 주제 · 모드(설득/강의/보고) · 청중 · 임무 · 분량 | 제목 · 테마 · 브랜드색 · 로고 · 금지사항 |

그다음 **목차를 먼저** 보여주고 승인받은 뒤에 만듭니다.
다 만들고 뒤집는 것보다 훨씬 쌉니다.

바쁘시면 **"그냥 빨리 만들어줘"** 라고 하시면 주제와 청중만 받고 나머지는 기본값으로 갑니다.

### 만들고 나서

| 필요한 것 | 방법 |
|---|---|
| 그대로 발표 | 브라우저로 열고 `F` 전체화면, `←→` 이동 |
| PDF로 배포 | `P` → PDF로 저장 |
| **PPTX로 직접 수정** | "이걸 pptx로 만들어줘" — 킷의 PPTX 규격(환산표·폰트·자동맞춤 금지)에 맞춰 만듭니다 |
| 테마 바꾸기 | `T` 키로 14종 순환. 마음에 드는 걸 말씀하시면 고정합니다 |

## 이 킷이 실제로 막는 것

- 제목 위 작은 대문자 라벨 — **금지**. 제목이 스스로 무게를 지닙니다
- 본문 21pt 미만 — 그건 폰트가 작은 게 아니라 **내용이 많은 것**입니다
- 한 장에 요소 6개 이상
- 이모지를 아이콘 대신 쓰기
- 매 장 다른 전환 효과
- 내용 없는 스톡 이미지 (악수·전구·오르는 화살표)
- 홍길동 / 99.9% / 010-1234-5678 같은 가짜 데이터
- 옅은 회색 글자 — 프로젝터에서 사라집니다
